# 🧮 Calculadora 1P-00-V01

Calculadora básica desarrollada en **Python**, utilizando programación orientada a objetos (POO).

El proyecto permite realizar operaciones matemáticas básicas desde una interfaz de consola, incorporando validaciones de entrada y manejo de excepciones.

## 🚀 Características

- **Suma:** suma dos números.
- **Resta:** resta dos números.
- **Multiplicación:** multiplica dos números.
- **División:** divide dos números, validando que el divisor no sea cero.
- **Potencia:** calcula la potencia de un número.

## 🛠️ Tecnologías utilizadas

- Python 3
- Programación orientada a objetos (POO).
- Manejo de excepciones (`try`, `except`).
- Funciones y estructuras de control.
- Entrada y salida de datos por consola.
